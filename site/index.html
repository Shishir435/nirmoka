See what's eating your disk.
On any operating system.

Nirmoka is a free, open source desktop app that puts a real graphical interface on the disk-usage tools power users already trust. Point it at a folder, watch the tree fill in, sort by size, and reclaim space — without memorising keybindings or squinting at du output.

निर्मोक (nirmoka) is Sanskrit for the skin a snake sheds — the dead layer a living system leaves behind. That is exactly what this tool helps you find.

A frontend, not another scanner

Nirmoka writes no disk scanner of its own. It runs an existing, proven command-line tool as a separate process, reads its structured output, and renders it. Backends are swappable behind an adapter layer, so no single upstream project can strand the app.

Cross-platform code from day one

One codebase for macOS, Linux, and Windows, tested on all three. macOS is packaged first, because the cleanup workflow runs on Mole and Mole is macOS-only. Different platforms can use different backends underneath, and the interface stays the same.

Small enough to be honest

Built with Tauri on the operating system's own webview, so the download is measured in single-digit megabytes. A disk cleanup tool that eats 300 MB of disk is a joke.

Safe by default

Destructive actions are previewable where the backend supports it. Deletion routes through the backend's own protections rather than a fresh, untested set.

Swappable by design

Each backend declares what it can do. The interface adapts, and replacing a backend is a contained change rather than a rewrite.

Planned backends

Backend Platforms Role
Mole macOS Rich cleanup, application uninstall, protected-path safety rules
ncdu macOS, Linux, BSD Baseline scan and delete, available everywhere
gdu macOS, Linux, Windows Fast parallel scan, ncdu-compatible export

Nirmoka bundles none of these. It detects what you already have installed and tells you how to get one if you have none.

Questions

Is Nirmoka free?

Yes. Free, open source, and licensed under Apache-2.0. There is no paid tier.

Is this a fork of Mole, ncdu, or gdu?

No. Nirmoka is an independent project that contains no code from any of them. It runs them as separate processes on your machine and reads their documented output. It is not affiliated with or endorsed by any of those projects.

Which backend do I need?

Any one of them. On macOS, Mole gives the most functionality. On Linux, ncdu is almost certainly already installed. On Windows, gdu is the path.

Will it delete something important?

Every path is validated at the adapter boundary before it reaches a subprocess, and the backend's own protections run as a second layer. Where a backend supports a dry run, you see the exact list before anything is removed. Where it does not, Nirmoka asks rather than pretending to preview.

How do I install it?

On macOS 12 or later, with Homebrew: brew install shishir435/tap/nirmoka. The formula builds from source, which takes a few minutes and brings a Rust and Node toolchain along as build dependencies.

A downloadable app needs an Apple Developer ID certificate, which needs a paid Apple Developer account, and there is not one yet — macOS refuses an unsigned download outright. A source build has no such problem, which is why it is the supported path for now. Linux and Windows build from a checkout.

Follow along

The architecture, adapter contract, and decision records are all public while the project is still being designed.
